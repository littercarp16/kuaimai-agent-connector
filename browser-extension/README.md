# 快麦本地 Agent 连接（测试扩展）

支持 Chrome 120+；当前验收浏览器为 Chrome 157 / macOS。

1. 在绫通网页复制最新连接请求，让本地 Agent 执行。连接器 0.3.2+ 会自动注册本机消息通道，并返回 `extensionDirectory`。
2. 打开 Chrome 的扩展管理页 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择返回的目录。若使用下载的 ZIP，先解压，选择包含 `manifest.json` 的目录。
3. 刷新原来的绫通网页，继续选择 ChatGPT / Codex 和会话。不需要保留扩展管理页。

首次安装后可一直复用，不需要手动填写端口。扩展仅支持以下两个来源（协议、域名和端口均需一致）：

- `http://lt.com:8085`
- `http://local.lt.com:8251`

通信链路：原网页 → 浏览器扩展 → 本机消息通道 → 本机连接器 → Agent。没有服务器中继、额外连接窗口或登录自启动项。扩展不会读取浏览历史或访问其他网站，不保存会话内容。

这是供测试的未打包扩展，尚未上架 Chrome Web Store。安装需要用户在浏览器中确认；连接器不会修改浏览器安全设置或强制安装扩展。商店分发需要单独发布，并核对商店分配的扩展 ID 与本机允许名单。

如提示“本机通道尚未就绪”，重新复制请求并让 Agent 执行；如果刚安装或更新扩展，请刷新网页。扩展 ID 固定为 `ahibjmmejhcabodghbdmdihdgkncaeca`。

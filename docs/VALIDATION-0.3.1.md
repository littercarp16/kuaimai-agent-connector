## 部署边界

正式和灰度来源的浏览器夹具通过，不代表已部署前端到线上。当前真实联调来源为指向本机的 `http://local.lt.com:8251`。

指向局域网的 `http://lt.com:8085` 需要 HTTPS；浏览器可能要求本地网络访问授权。站点如设置 CSP，connect-src 需允许 `http://127.0.0.1:*`。

访问 token 仅在内存；恢复凭据限当前标签页 sessionStorage、绑定网站与实例、8 小时失效。浏览器新标签页或后台重启后通过新的复制请求授权，不需要填写端口。

## 本次发现并修复

- **待接入状态无法重新复制**：旧请求等待 Agent 时，前端 `settingsBusy` 会阻止复制新请求。现在允许未连接的 Codex 准备流程重新复制，先使旧异步结果失效并取消等待，再生成新请求；已有运行和已连接的操作仍受忙碌保护。
- **后台升级使发现结果过时**：网页可能使用升级前的实例标识领取授权。对于服务在消费授权前明确返回的 409，网页重新发现实例后继续领取；网络中断等结果不明的写请求仍不会自动重发。

修复在本地前端生效，网页 SDK 源码同步保留在本仓库。连接器运行时仍使用已发布的 npm 0.3.2，两个修复不要求重新安装运行时；远端网站需部署更新的前端。npm 0.3.2 包内的网页 SDK 不包含后续的 409 重发现修复。

回归：HTTP Vue 实际组件的重复复制、绑定、收发、刷新和断开流程通过；两个 HTTPS 直连来源（含模拟旧实例 409）与两个 HTTP 扩展来源共 4 个浏览器用例通过。
